# Графика тренажёра — что нужно сгенерировать

В курсе стоят **5 заглушек**. Каждая — блок `.ku-img.zb-ph` внутри `index.html`
с двумя атрибутами:

- `data-gen-file` — путь, по которому нужно положить готовый файл;
- `data-gen-prompt` — промт для генерации.

## Как подставить картинку

1. Сгенерируй изображение по промту.
2. Сохрани его **точно по пути из `data-gen-file`** (папка `assets/gen/` уже создана).
3. Ничего в разметке менять не нужно: `<img>` уже указывает на этот путь, и как
   только файл появится, плашка-заглушка исчезнет сама
   (`.ku-img img[src]:not([src=""]) ~ .ku-img__ph { display: none }`).

## Технические требования

- Формат: JPEG, качество ~78, прогрессивный. При замене расширения на `.png`
  или `.webp` поправь `src` и `data-gen-file` в разметке.
- Вес: до ~200 КБ на файл — курс должен быстро открываться в LMS.
- Соотношение сторон указано у каждой позиции: контейнер задаёт `aspect-ratio`,
  картинка кадрируется по `object-fit`.
- Без текста, надписей и логотипов на изображении: курс переводится и
  «переодевается» под подраздел ЦА, вшитый текст этому мешает.

## Что графикой НЕ является

Остальные 22 изображения в `assets/` — реальные фотографии из материалов
методиста (инвентарь, котлеты, положение щупа, бракераж, обе памятки).
Их генерировать не нужно и заменять не нужно.

Если понадобится заменить фото на единообразные иллюстрации — заведи для них
такие же блоки `.zb-ph` с `data-gen-file`/`data-gen-prompt`, чтобы конвейер
остался одинаковым.
